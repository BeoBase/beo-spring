# README.md file

# Project name: Beo Spring

> Handle back-end api requests from React front-end, database transactions and business logic.

---
## 🚀 Features

- Feature 1: User authentication, and registration
- Feature 2: Money tracking, export and import transactions
- Feature 3: Host on the cloud, support full-stack web app

---

## 🛠 Tech Stack

- **Java Version:** Java 25
- **Framework:** Spring Boot 4.1.0
- **Build Tool:** Maven (`mvnw`)
- **Database:** PostgreSQL

---

## 🏃 Getting Started

- Install IntelliJ for Java Spring Boot
- Get access token from Bitwarden and set env variables
- Run the run-local.sh script to fetch the .env file
